# AGNEX Technology — Official Brand Identity Assets

This directory contains the authoritative brand assets for **AGNEX Technology**.

## Brand Identity Standards
- **Brand:** AGNEX Technology
- **Tagline:** Engineering What's Next.
- **Brand Promise:** Ideas, engineered into impact.
- **Brand Concept:**
  - **AG:** Engineering, foundation, precision
  - **NEX:** Next, forward movement, progress
  - **X:** Technology × People × Ideas (intersection, transformation, collaboration)

## Core Palette
- **Base (Black):** `#0B0D10`
- **White:** `#F7F8FA`
- **Graphite:** `#20242B`
- **Steel:** `#7C8490`
- **Official Blue Accent:** `#057AEF` (The vibrant azure blue in the soaring arrow, triangle in 'A', and 'NEXT')

## Asset Files
- **`agnex-logo.svg` / `agnex-logo.png`** — Original authoritative logo for light surfaces.
- **`agnex-logo-light.svg` / `agnex-logo-light.png`** — Faithful inverted version for dark backgrounds (`#0B0D10`). Preserves the exact geometry, typography, spacing, and vibrant blue arrow (`#057AEF`) while setting the dark lettering to `#F7F8FA`.
- **`agnex-mark.svg` / `agnex-mark.png`** — The standalone X + soaring forward arrow mark for icons, avatars, and compact spaces.
- **`agnex-favicon.svg`** — Scalable vector favicon mark.
- **`agnex-og.png`** — 1200×630 Open Graph card for social sharing and search engines.

## Usage Guidelines
1. **Never alter proportions or geometry:** The relationship between the wordmark and soaring blue arrow is fixed.
2. **Never change the blue color:** `#057AEF` is the single source of truth for the brand arrow.
3. **Contrast:** Always use `agnex-logo-light` on dark surfaces (`#0B0D10` to `#20242B`) and `agnex-logo` on light surfaces.
